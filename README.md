# 出海工作室

面向自有阿里巴巴国际站店铺的本地单用户产品准备工具。Python 3.12+，无第三方依赖。

## 运行

```bash
cd /workspace/-
python app.py
```

默认仅监听本机 8000 端口。可用 `PORT` 改端口，`STUDIO_DATA_DIR` 指定数据目录。设置 `STUDIO_ACCESS_PASSWORD` 启用浏览器登录（用户名 `studio`），非本机监听强制要求密码。公网部署必须使用 HTTPS。Render 部署说明见 [DEPLOY.md](DEPLOY.md)；尚未实际部署。

## 已实现

- 浏览器上传 JPG / PNG / WebP，等比居中排版、背景填充和产品占比调整，下载 1200 × 1200 PNG。原图不上传服务器。
- 产品资料编辑，按已填内容整理英文描述模板；不含 AI 翻译、图片生成或背景移除。
- SQLite 保存与重新载入文字草稿，导出 ZIP（JSON 和文本资料）。主图需单独下载，刷新页面后需重新上传原图。
- 明确区分本地草稿、资料导出与平台发布。
